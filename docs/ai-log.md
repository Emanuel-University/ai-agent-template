# AI log

Your own account of how AI was used in this project. You write it, not the
agent (see docs/hard-rules.md). Add one entry after each task you worked on
with an agent, while you still remember what happened.

Each entry answers four questions. The third one, what was verified, has two
lines: what you checked yourself and what the tests checked.

- Generated by AI: what the agent produced, by feature, what you asked for and
  which provider you used.
- Written by me: what you wrote or rewrote by hand, and why.
- Verified by me: what you checked yourself (read the diff, ran the app, tried
  each behavior) and what you found wrong.
- Verified by tests: which tests ran, who wrote them, and the result. A test
  the agent wrote and ran is not a check you made: keep it on this line.
- Decided: the choices you made, with the reason, and the agent's proposals
  you refused.

Vague entries do not count. "I used AI and checked everything" answers none of
the four questions.

## Entry format

```
## YYYY-MM-DD: feature or task
- Generated by AI: ...
- Written by me: ...
- Verified by me: ...
- Verified by tests: ...
- Decided: ...
```

## Example (delete it when you add your first entry)

## 2026-10-09: Login page
- Generated by AI: the login page and its browser tests, with Copilot, from
  docs/specs/login.md.
- Written by me: the error messages; a user would not have understood the agent's.
- Verified by me: ran the app and read the diff. With an empty field the
  "Conectare" button stayed active; asked for a fix and checked again.
- Verified by tests: the agent's Playwright tests, one per behavior line:
  3 passed.
- Decided: refused the "Forgot password" link the agent proposed; the spec
  leaves it out for now.
